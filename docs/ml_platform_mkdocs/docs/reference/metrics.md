# メトリクスと数式

この基盤の標準指標は `mae`、`rmse`、`r2` です。モデル選択指標は `model.selection_metric` で指定します。

## 記号

- \(y_i\): 実測値
- \(\hat{y}_i\): 予測値
- \(n\): validation データ数
- \(\bar{y}\): 実測値の平均

## MAE

平均絶対誤差です。

$$
\mathrm{MAE} = \frac{1}{n}\sum_{i=1}^{n}|y_i - \hat{y}_i|
$$

| 特徴 | 説明 |
| --- | --- |
| 解釈 | 平均的にどれだけ外れるか |
| 外れ値感度 | RMSE より低い |
| 用途 | 業務上の絶対誤差を重視する場合 |

## RMSE

二乗平均平方根誤差です。

$$
\mathrm{RMSE} = \sqrt{\frac{1}{n}\sum_{i=1}^{n}(y_i - \hat{y}_i)^2}
$$

| 特徴 | 説明 |
| --- | --- |
| 解釈 | 大きな誤差を強く罰する平均誤差 |
| 外れ値感度 | 高い |
| 用途 | 大外しを避けたい場合、選択指標の標準 |

## R2

決定係数です。

$$
R^2 = 1 - \frac{\sum_{i=1}^{n}(y_i - \hat{y}_i)^2}{\sum_{i=1}^{n}(y_i - \bar{y})^2}
$$

| 特徴 | 説明 |
| --- | --- |
| 解釈 | 平均予測に対する改善度 |
| 範囲 | 通常は 1 に近いほど良い。負になることもある |
| 用途 | 相対的な説明力の確認 |

## 選択指標

`model.selection_metric` が `rmse` または `mae` の場合、小さい値が良いとみなされます。`r2` の場合、大きい値が良いとみなされます。

| 指標 | 良い方向 | 注意 |
| --- | --- | --- |
| `rmse` | 小さい | 外れ値に敏感 |
| `mae` | 小さい | 大外しの重みが弱い |
| `r2` | 大きい | 目的変数分散が小さい場合は不安定 |

## 評価時の推奨確認

1. `leaderboard.csv` で順位を見る。
2. `prediction_vs_actual` で線形性・外れを確認する。
3. `residual_histogram` で残差の偏りを見る。
4. `residual_vs_predicted` で予測値帯ごとの誤差傾向を見る。
5. `best_vs_ensemble_summary.csv` でアンサンブルの改善を確認する。

単一指標だけで判断せず、業務上の誤差コスト、モデルの説明性、推論速度、運用環境依存を合わせて判断してください。
