- R03: BLAS/OpenMP thread environment defaults are currently set in `clearml/app.py`, `scripts/local_run.py`, and `scripts/make_sample_data.py`.
- R15: `ui_params`, `ui_value`, `default_ui_params`, and `pipeline_ui_params` remain in ClearML runtime files and mapping tests. Rename/migration should stay compatibility-focused.
- R17: Manual `sys.path` bootstrap exists in `clearml/_entrypoint_bootstrap.py` and `scripts/_bootstrap.py`.
- R19: `TABLE_SUFFIXES` exists in `pkgs/core/src/ml_platform_core/io.py` and is currently used for recursive table discovery.
- R20: `set_dotted_path = set_by_dotted_path` remains in `pkgs/core/src/ml_platform_core/config.py`; usage/removal requires confirmation by search and compatibility checks.
- R21: `.pre-commit-config.yaml` and `.gitlint` are absent. Original intended settings are not recoverable from the current tree alone.
- R22: `.gitattributes` is absent. Original intended settings are not recoverable from the current tree alone.

- R25: No `*.code-workspace` file is tracked. Intended workspace layout requires confirmation before restoration.
- R27: `Registry` exists in `pkgs/core/src/ml_platform_core/registry.py`; implementation/use decision is deferred to the relevant review branch.
