# Review Workspace

This directory keeps review-response notes, migration records, and historical
inputs used while simplifying the repository.

Active product documentation lives outside this folder, primarily in
`../SPEC.md`, `../ROADMAP.md`, and `../ml_platform_mkdocs/`.

Treat `source/` as archived review input. Do not use it as current product
requirements without checking the newer implementation and docs first.

Current cleanup tracking lives in `SIMPLIFICATION_FIX_MAP.md` and
`SIMPLIFICATION_REMAINING_BACKLOG.md`.
